## Inventory & Sales Management System 2.0

This is a version 2 of Inventory Managment System. It is a python based system that is for a small tech business that has a few employees, and would like to change from book keeping, and manual tracking of their inventory, sales, customer information, by book to a system that lives on a desktop, and employees can manage everything fron this desktop system.

# FEATURES
**Staff Management**: Manage all staff information, as well as their credentials, system priviledges
**Customer Management**: Manage all their customers, track their past purchases, track all their receipts, and have insights like Customer Lifetime Value
**Inventory Management**: Track all inventory when new stock comes in, when stock get purchased, returned, and provice all necessary insights
**Authentication System**: Staff profiles, are protected keeping all their confidentail information safe

## Future features
